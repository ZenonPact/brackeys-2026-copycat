# Jam Plan — Copycat (Brackeys Game Jam 2026)

Small playable milestones over big plans. Each milestone should be runnable.

## Milestones

- [ ] **M0 — It compiles and opens a window.** `make run` shows a raylib window.
- [ ] **M1 — Core mechanic prototype.** The "copycat" idea playable in its ugliest form.
- [ ] **M2 — Loop closes.** Win/lose state, restart. A stranger could play it.
- [ ] **M3 — Feel.** Sound, screen shake, tuning. Cut scope here, not in M1–M2.
- [ ] **M4 — Web build.** emscripten build runs in a browser; upload to itch.io.
- [ ] **M5 — Ship.** Page, screenshots, submit before the deadline, not at it.

## Notes

- Fallback: if the web build fights back after M4 starts, ship native mac and move on.
